# Sign-up form assessment

Expo and TypeScript starter with Expo Router, react-hook-form, Zod, and @hookform/resolvers installed.

## Run

```bash
npm ci
npm start
```

## Checks

```bash
npm run typecheck
npm run lint
```

The entry screen is `src/app/index.tsx`. This repository currently contains initialization only. The sign-up form, validation, submission handler, and confirmation screen are not implemented.

See START_HERE.md for setup and verification notes.
